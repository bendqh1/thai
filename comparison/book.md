* **ขึ้น = more / increasing**
* **ลง = less / decreasing**

| More / Increasing | Less / Decreasing |
|---|---|
| ยาวขึ้น = longer | สั้นลง = shorter |
| คล้ำขึ้น = darker / more tanned | คล้ำลง = lighter |
| อ้วนขึ้น = fatter | ผอมลง = thinner |
| รวยขึ้น = richer | จนลง = poorer |
| โกรธขึ้น = angrier | เย็นลง = calmer |
| สงบขึ้น = calmer | ร้อนขึ้น = hotter |
| ใหม่ขึ้น = newer | เก่าลง = older |
| กลัวขึ้น = afraider | กล้าหาญขึ้น = braver |
