* บาง is not for questions, rather, บาง is a plurality marker.
* บ้าง is a question particle.

## บาง

The word บาง can have several meanings:

* บาง == some
* บาง == thin
* บาง == village
* บางที == sometines
* บางที่ == somewhere

Phrase examples

* คนบางคน
* ครั้งบางครั้ง
* ผมชอบเล่นแบดมินตันบางครั้งครับ

## บ้าง

มีอะไรบ้าง
เป็นยังไงบ้าง
เป็นอะไรบ้างครับ?
คุณมีอาการอะไรบ้าง
คุณชอบเล่นแบดมินตันบ้างไหม

## Notes

* Never say บางๆ
* Never say บ้างๆ
