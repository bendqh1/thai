# Thai Keyboard Layout Notes

## Four Modes

1. Regular
2. Regular-Shift
3. Caps Lock
4. English (for special symbols only)

## Key Groups

### Left Bunch
- P and BP letters are on the left.

### Middle Bunch
- Ek, To, Tri, Jat-ta-wa (middle, clockwise)

### Right Bunch
- All S keypads
- Most K keypads
