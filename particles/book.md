### General (used by everyone)

| Thai | Meaning |
|------|----------|
| นะ | seeking agreement, softening, reminder |
| เถอะ | suggestion, encouragement |
| สิ | urging, "go ahead", "do it" |
| ล่ะ | then, so, topic shift |
| หรอก | contradiction, reassurance |
| หรอ | casual question / confirmation marker |
| เหรอ | surprise, confirmation |
| ปะ | casual confirmation-seeking, "right?" |
| เนี่ย | points out / highlights something |
| ไง | explanation, "you see?" |
| มั้ง | probably, I guess |
| แหละ | exactly, indeed |
| เลย | strong emphasis; completely; right away |
| นา | soft agreement-seeking |
| เนาะ / เนอะ | "right?", seeking agreement |
| โนะ | "right?", confirmation-seeking |
| อะ / อ่ะ | filler, topic introduction, softener |
